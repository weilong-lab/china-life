# 中国人的一生

按中国大陆各省和香港、澳门、台湾的真实统计随机出生的人生模拟。省份、城乡、户口、家境决定起点，可以选 1950–2016 之间任何一年出生，每年都有当年的大事：自然灾害、经济事件、教育和就业政策，经历三年饥荒、文革、上山下乡、恢复高考、改革开放、计划生育、国企下岗、大学扩招等历史，从出生证明一路过到结案。

就业有考公（国考省考、选调生、事业编、教师编、军队文职、三支一扶，应届和社招难度不同）、大厂、外企、央国企和灵活就业；学历有普通高考、专升本、成人高考、自考、网络教育、全日制和非全日制硕士、读博和出国留学；人生的另一面也会发生：被骗、醉驾、借卡、被骗去电诈园区、网赌、受贿、坐牢和出狱以后。

在线玩：https://weilong-lab.github.io/china-life/

数字都是根据公开统计做的近似，只为让一生的大致走向贴近现实。
